Return Comment Analyzer

The Return Comment Analyzer was developed to automate the review of over 500 return comments per week and analyze 100,000+ historical comments for product feedback. The tool identifies customer sentiment associated with a customer ID, providing valuable input for a churn prediction model. It breaks down comments into identified themes and assigns a 1-5 score to each theme (1 = most negative, 3 = neutral, 5 = most positive). The final version aggregates positive and negative scores for comprehensive product feedback evaluation and customer sentiment analysis.
