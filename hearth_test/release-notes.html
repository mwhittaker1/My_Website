Release notes: what’s real and what’s not

Test build, October 30, 2026. This page is the honest list. If something isn’t listed as real, assume it is not.

Real

WhatDetails
Menu items, names, categories, pricesREAL DATARead from the bakery’s GoDaddy store with a read-only token. Only items switched on for the Online Ordering channel are shown. Display names (like “Breakfast Sandwich”) can be overridden in a config file.
Pickup rulesREAL LOGICLater of 24 hours’ notice or the next open window, up to 14 days ahead, in hourly windows, Eastern time, including the November 1 clock change. Covered by automated tests, using the same code the page runs.

Blackout dates and hours editingREAL LOGIC, LOCAL SAVEThe rules honor blackout dates. But edits made in Test admin are saved in your browser only until the downloaded settings.json is committed.
Test clockREALThe “Set a date and time to test from” control drives the menu’s pickup times, the cart, the checkout check, and the admin preview. It is remembered in your browser.

Not built yet / known limits

  • No server-side checks. This site is static, so the pickup time is only re-checked in the browser. A real launch needs a server to re-check time and price before taking an order.
  • It is only online while the PC is on. The test server runs on the helper’s PC, and the public address (a free tunnel) changes each time it is started. This is a test setup, not hosting.
  • No emails are sent. Orders are logged at Test submissions instead. Emailing the bakery or customers needs a real mail service and is not built.
  • The admin page has no password, and neither does the page that shows this browser’s own log. It only changes your own browser’s settings, so that’s safe for now, but it is not a real admin yet.
  • No photos or descriptions. GoDaddy has none for these items. They’ll come from a file keyed by SKU code once collected.
  • Contact form, news, and visit sections are still the prototype’s placeholder content. The contact form shows a copy-and-paste fallback instead of sending.
  • Keandro font not used. The licence found is desktop-only, so a web licence is needed before it can go on a website.
  • Holiday and Catering items appear as GoDaddy categorizes them. Seasonal items are switched on and off by hand in GoDaddy.
